# 🛍️ Product Comparator – Responsive Web Demo

This is a functional front-end prototype for a product comparison platform. It allows users to search for a product and view different store options with prices, badges, and links to external websites.

## 🔍 Features

- Search bar to filter products by name
- Display of products with:
  - Price and store name
  - Visual badges (e.g., Free Shipping, Featured Store, Gold Medal)
- Responsive design using Bootstrap
- Demo version with static data (JavaScript array)

## 🧰 Technologies Used

- HTML5
- CSS3 (Bootstrap 5)
- JavaScript (Vanilla)
- Netlify (for hosting)
